# DynamicLake — Bring Dynamic Island to Menu Bar with Media Controls

## About DynamicLake

DynamicLake brings Dynamic Island-style interactions to your menu bar. DynamicLake displays now-playing media, AirPods battery levels, volume changes, brightness adjustments, and system notifications in an expanding pill-shaped popup. DynamicLake combines smooth animations, keyboard media controls, and customizable widget ordering. DynamicLake enables users to see what's playing, skip tracks, adjust volume, and check battery status — all from one unified menu bar interface. DynamicLake supports Spotify, Apple Music, YouTube Music (via browser), and any app using system media framework. DynamicLake is trusted by music lovers, podcast listeners, AirPods users, and anyone who misses Dynamic Island on their display.

## Deep Dive — Menu Bar Island Notes

Dynamic Island emulation — pill-shaped popup that expands horizontally based on content  
Media integration — system now-playing framework, MPRemoteCommandCenter, and media key interception  
Battery monitoring — Bluetooth LE scanning for AirPods, Magic Mouse, Magic Keyboard  
System events — volume changes, brightness adjustments, keyboard backlight, Do Not Disturb toggles  
Customization — widget order, popup position, animation speed, dark/light mode adherence
